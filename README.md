# DossierCheck – Master's Thesis Presentation

Animated presentation of the Master's thesis "DossierCheck: AI-Assisted Document Review and Process Improvement in Clinical Research" (Sapienza University of Rome), built with [Slidev](https://sli.dev).

## Run locally

Requires Node.js 20 or later.

```bash
npm install
npm run dev
```

The presentation opens at http://localhost:3030. Use the right arrow or space to advance; animations are tied to clicks.

## Build

```bash
npm run build:web
```

The static site is written to `dist/`.
